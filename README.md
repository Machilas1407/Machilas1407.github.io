# Portfólio — Marcello Queiróz

Portfólio profissional estático, pronto para publicação no GitHub Pages.

## Publicar

1. Crie um repositório público no GitHub, por exemplo `portfolio`.
2. Envie `index.html`, `.nojekyll` e este `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/ (root)` e clique em **Save**.

O endereço ficará disponível no formato:

`https://SEU-USUARIO.github.io/portfolio/`

## Domínio próprio

Em **Settings → Pages → Custom domain**, informe o domínio desejado. Antes de configurá-lo, faça a verificação do domínio nas configurações da sua conta do GitHub.

## Atualizações

Substitua o `index.html` no repositório e confirme a alteração. O GitHub Pages publicará a nova versão automaticamente.
